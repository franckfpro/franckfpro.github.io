# 📅 Mois 1 : Fondamentaux Python + Bibliothèques Data
## Semaines 1-2 : Renforcement des bases

### Python avancé :

- Compréhension approfondie des listes en compréhension, générateurs, décorateurs.
- Gestion des fichiers (CSV, JSON, TXT) avec open(), csv, json.
- POO : Classes, héritage, méthodes magiques (__init__, __str__).

### Outils :

- Maîtriser Jupyter Notebook ou VS Code pour le développement.
- Utiliser Git pour versionner ton code.

## Semaines 3-4 : Introduction aux bibliothèques data

### NumPy :

- Tableaux (ndarray), opérations vectorisées, broadcasting.
- Indexation avancée, masques booléens.

### Pandas :

- DataFrame et Series : création, manipulation (filtrer, trier, grouper).
- Nettoyage de données : gestion des valeurs manquantes (NaN), types de données.

### Projet :

- Analyser un dataset simple (ex : Titanic) : calculer des statistiques, filtrer les données.


# 📅 Mois 2 : Analyse de données et Visualisation
## Semaines 5-6 : Analyse exploratoire (EDA)

### Pandas avancé :

- merge, concat, pivot_table.
- Fonctions d’aggrégation (groupby, agg).
- Time series : datetime, résampling, rolling windows.

### Visualisation :

- Matplotlib : Graphiques de base (lignes, barres, histogrammes).
- Seaborn : Graphiques statistiques (sns.boxplot, sns.scatterplot, sns.heatmap).

### Projet :

- Créer un rapport d’EDA sur un dataset (ex : House Prices) avec visualisations.

## Semaines 7-8 : Introduction au Machine Learning

### Scikit-learn :

- Préprocessing : StandardScaler, OneHotEncoder, train_test_split.
- Modèles de base : Régression linéaire, classification (Logistic Regression, Random Forest).
- Évaluation : Métriques (accuracy_score, mean_squared_error), cross-validation.

### Projet :

- Entraîner un modèle de régression sur le dataset House Prices.


# 📅 Mois 3 : Approfondissement et Projets
## Semaines 9-10 : Machine Learning avancé

### Feature Engineering :

- Sélection de features, encoding, gestion des outliers.

### Modèles avancés :

- Gradient Boosting (XGBoost, LightGBM).
- Introduction aux pipelines (Pipeline, ColumnTransformer).

### Projet :

- Participer à une compétition Kaggle (ex : Store Sales Forecasting).

## Semaines 11-12 : Projets personnels et Optimisation

### Projets libres :

- Choisir 2-3 datasets et appliquer tout ce que tu as appris (EDA + ML).
- Exemples : Prédire des prix, classifier des images (avec PIL ou OpenCV si tu veux aller plus loin).

### Optimisation :

- Hyperparamètre tuning (GridSearchCV, RandomizedSearchCV).
- Sauvegarder/charger des modèles (joblib, pickle).

### Bonus :

- Introduction à SQL (pour interroger des bases de données) ou Dask (pour les gros datasets).
